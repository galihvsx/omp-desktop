OMP Desktop — Peta Wireframe
Adaptasi UI ZCode (zai-org/ZCode v3.14.3) untuk shell desktop omp · prototype lo-fi ·
Prinsip adaptasi. ZCode = satu library UI React (packages/ui) yang dirender dua host tipis (Electron desktop + web), agent-nya subprocess CLI via stdio NDJSON — keluarga arsitektur yang sama dengan omp-desktop (host Go spawn omp --mode rpc). Yang diport: struktur shell, pola conversation, dock permission, sistem token theming. Yang tidak diport: lapisan binary-RPC/ACK/replay (VS Code-style), service accessor ~40 service, multi-transport remote.

Komponen ZCode yang sengaja TIDAK diport (dengan alasan)
Komponen ZCodeAlasan tidak diadaptasi
packages/rpc: binary framing 13-byte, PersistentProtocol ACK/replay/KeepAlive, Pause/Resume + watermark, ChannelClient/ChannelServer, ProxyChannelMenyelesaikan masalah transport byte-stream/WS/TCP yang tidak dimiliki Wails (event sudah message-framed). Pengganti: seq-cursor afterSeq replay di level semantik.
RemoteServiceAccess (~40 service proxy), multi-remote /ws/remote/:id, SSH/WSL host, workspaceConnectionRegistryProduk client-server; omp-desktop = host Go tipis single-user.
Browser-use pane, whiteboard, CUA permission panel, resource-manager window, replay view, coding-plan quota-reset UIFitur spesifik ZCode/Electron; bukan kebutuhan shell omp v1. Bisa jadi fase lanjutan (quota UI ada di states).
workflow-graph / workflow-timeline (dynamic workflow, token keluarga warna khusus)Di omp dipetakan ke tool card TODO/plan + side pane Tasks — satu mekanisme, bukan dua.
git-graph, Shimmer, ai-elements/confirmation.tsx, slash whitelist built-in, ToolSnapshotFieldNotice, BackgroundTaskElapsedLabel (JSX-nya)Dikategorikan dead/inert oleh studi; durasi dari fact protokol (activeMs/endedAt), daftar command dari katalog CLI.
Theming (port utuh)
Token semantik --color-* di @theme Tailwind v4; blok :root → .dark → .theme-zai-light/dark; skala text-ui-* = calc(--ui-font-size ± n), appearance 12–20px tanpa menyentuh root font-size; pre-paint theme seed (no FOUC); color-mix(in oklab) untuk hover/selected.
Integrasi (adaptif)
Frame NDJSON stdio + schema validation (zod) di boundary; command envelope {commandId uuidv7, baseRevision, type} + ACK status; seq-cursor replay (afterSeq) sebagai ganti binary replay; coalescer delta 1.5s/96-item untuk sesi background; stderr drain + kill-tree saat shutdown.
Ditinggalkan (dead weight ZCode)
Binary 13-byte framing, PersistentProtocol ACK/replay, ChannelClient multiplexing, ~40 RemoteServiceAccess, Pause/Resume watermark, v4 subscription barrier — semua menyelesaikan masalah yang tidak dimiliki Wails. Juga: slash whitelist built-in ( authority = katalog CLI), Shimmer, ai-elements/confirmation.tsx.

10 · Edge states
Semua state non-ikir yang wajib punya wajah UI. Sumber: useWorkspaceServicesResolution, runtime restart faults, empty/compact/quota.
Reconnecting / restart child
Koneksi ke child omp terputus — menyambung ulang…
Resync semantik: kirim seq cursor (afterSeq), host mereplay event setelah cursor. Frame yang sudah di-send() tidak pernah dibuang.
Child exited
Proses omp keluar (exit 1) — stderr tersimpan.
Shutdown order ZCode: stdin EOF → tunggu 1.8s → force kill-tree (Windows: taskkill /T). Parse error frame = tutup transport.
